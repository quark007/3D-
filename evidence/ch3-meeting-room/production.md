# 遵义核心会议室制作简报

以全景近端居中、朝南的视角建立桌边和窗框的透视。内空 4.6 × 6.4 × 3.4 米。西窗、东柜和活动座椅共同决定环行宽度。桌中心略偏西以让开柜体。两侧各八席，两端各两席。

| 参考视角 | 可见依据与制作取舍 |
|---|---|
| 核心全景 | 右侧窗格提供主要日光，左侧镜柜有凸起的冠饰。深色桌面前大后小，前排椅背遮住近端地面。保留明墙与暗木之间的明度差。 |
| 长桌与火盆 | 长边桌裙厚，桌面边缘有浅色磨痕，窄木扶手与交叉支腿可见。低机位从桌裙下沿看见灰黑盆沿和木架。 |
| 双柜与挂钟 | 上半幅是广角实景，下半幅是绘画。采用上半幅判断柜门分格、镜面比例和左墙位置。挂钟尺寸与位置按任务给定，照片像素不足以辨识钟面细节。 |

```text
北端机位 → 近端两椅 → 长桌 / 下方火盆 → 远端两椅 → 南墙
西墙 → 凹窗 / 底排彩玻 → 通道 → 八椅 → 桌 ← 八椅 ← 通道 ← 东墙双柜 / 钟
天花 → 吊杆 → 荷叶玻璃罩 → 桌面记录本与墨水瓶
```


## 交付与复核

Cycles 源场景保留 20 个共享同一 Mesh 的座椅对象，单椅 586 三角面。导出阶段为每把椅子分配独立光照 UV，再按材质合批。窗侧冷光、吊灯暖光与炭盆下光参与 Cycles Diffuse 烘焙。带颜色的 Diffuse 结果绑定到 glTF 基色的 TEXCOORD_1，AO 绑定到 occlusionTexture 的同一坐标集，藤编法线沿用 TEXCOORD_0。母版保留独立静态对象 UV 和原型椅的光照 UV，逐椅 UV 以最终 GLB 为准。

家具落地和通道按世界坐标网格测量，包含侧排座椅与凸出的东柜。通道最小值 0.95546 米。挂钟靠墙安装，木壳连表盘实测高 50.00、宽 22.00、深 11.00 厘米。地板板面标高为零，桌、椅、柜和炭盆木架的支撑最低点与其相接。

逐三角形检查本地 Draco 解码后的 UV1，共 18,406 面，正面积相交 0 对，退化 0 面。GLB 内含 16 个绘制图元。Edge 无头 WebGL 使用工程本地 Three.js r186 和 Draco 加载独立 GLB，全景机位在 1000 × 660 记录 32 次绘制，在 390 × 844 记录 22 次。竖屏数据来自桌面浏览器。三张 PNG 供与工作树外原照片并排查看，全景按照片估计机位，未取得原相机内参。
