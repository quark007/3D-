# 遵义会议会址摄影对照

桌面与竖屏各有四张实机图。外景以院内斜向看主楼、从石板地沿阶看门廊为参照，室内以桌端斜看西窗、从西侧平视东壁为参照。原片缺少测量控制点、拍摄位置和焦距，机位按可见建筑特征匹配。

| 实机图 | 对照与实现 |
| --- | --- |
| 01 主楼 | 航拍显示曲尺形主楼、歇山瓦顶和老虎窗。低角度近照能辨深砖券面、浅灰柱头和菱形饰面。模型采用正面七跨、短边三跨，楼梯收到两端廊内。 |
| 02 院落 | 门楼、配房轮廓、端部石阶和古树以航拍与湿地低机位交叉定位。中央步行区增设错缝石板，板缘有倒角和毫米级高差。树干与冬季枝梢围绕同一根部缩放。 |
| 03 西窗 | 按馆长导览，小客厅由南廊向东抵达。东翼西向墙面开洞，外窗和室内切片按同一窗槛标高和 5×5 分格对位。普通窗格透明度用 alpha 0.12，粉、黄底格分别为 0.38、0.32。窗外取自同一院落模型、冬雨天空及雨丝。 |
| 04 东壁 | 本地三张资料图和纪念馆说明用于核对桌、折叠藤椅、吊灯、双柜、穿衣镜、挂钟与炭盆的相互位置。照片拼图只使用上半幅实拍。桌边毛笔、柜门拉环和炭块裂纹属于近景表现上的补配。 |

馆长导览记主楼面阔 25.75 米、进深 16.95 米、通高 12 米，并描述十个券拱和东西两端楼梯。项目沿用相同的主楼主体包络，保留原有可行走区域和剧情锚点。纪念馆两篇资料分别记小客厅为 27 和 36 平方米。本版沿用已验证通行的 6.4 × 4.6 米净界，约 29.44 平方米。窗在东翼的精确轴线、披檐出挑、历史树冠和 1935 年的逐块铺装仍属推定。[馆长现场导览](https://movement.gzstv.com/news/detail/rjGDY/) · [遵义会议纪念馆供稿](https://news.12371.cn/2015/01/07/ARTI1420596304506715.shtml)

室外参照包括本轮从新闻图片原址取得的四张航拍、门楼、转角及拱券细部图，并使用项目以前留存的三张带来源记录的新闻照片。室内比对使用工作区的三张参考图。修缮期的脚手架、现代游览设施及 1964 年题匾均未作为 1935 年的建模依据。网络原图保存在 Git 忽略目录。[修缮现场照片](https://www.cqnews.net/web/content_1539534598842191872.html) · [司法部转载新华社图文](https://www.moj.gov.cn/pub/sfbgw/zwgkztzl/2021nzt/20210420fdbnl_2329/hsjy/202105/t20210511_391697.html)

浏览器记录由 `python tools/verify-zunyi-room.py --photos` 生成。1280×800 和 390×844 均在本机 Edge 运行，竖屏启用触控模拟。FPS 为各状态至少 1.5 秒的应用渲染帧均值。峰值覆盖进出、五张卡片、五次重复往返和 23 个锚点各四向取景。资源按同源 URL 路径去重，加上入口 HTML 的传输正文大小。窗洞另用 Blender 对最终室外 GLB 逐格射线检测，见 `window-geometry.json`。
